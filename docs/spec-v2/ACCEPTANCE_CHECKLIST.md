# قائمة القبول — لا تعتبر المهمة مكتملة دون دليل

## الأمان والعزل
- [ ] مستخدم من العيادة A لا يستطيع قراءة أو تعديل أي سجل للعيادة B.
- [ ] الاختبار يشمل API والبحث والتقارير والملفات والمهام الخلفية.
- [ ] صلاحيات كل دور مطبقة على الخادم، وليس الواجهة فقط.
- [ ] الأسرار غير موجودة في المستودع أو سجلات التشغيل.
- [ ] سجلات التدقيق تسجل العمليات الحساسة دون كشف بيانات زائدة.

## البيانات الطبية
- [ ] حفظ المصدر والوقت والفاعل لكل معلومة مهمة.
- [ ] تعديل السجل لا يمحو تاريخ التعديل حسب السياسة المعتمدة.
- [ ] المخرجات المستخرجة آليًا مميزة عن البيانات التي أكدها الطبيب.
- [ ] لا يوجد تشخيص/روشتة نهائية آلية دون اعتماد الطبيب.
- [ ] لا تُستخدم بيانات حقيقية في الاختبارات العادية.

## المال والاشتراكات
- [ ] اختبارات حساب الفواتير والخصومات والعمولات والاستردادات.
- [ ] منع تكرار الدفع أو تسجيل المعاملة مرتين.
- [ ] إلغاء الاشتراك لا يحذف البيانات تلقائيًا.
- [ ] حدود الاستهلاك والتكلفة قابلة للقياس والتنبيه.

## الرسائل والتكاملات
- [ ] عدم إرسال محتوى طبي حساس في إشعار واتساب عادي.
- [ ] إعادة المحاولة بحدود ومنع التكرار.
- [ ] تسجيل الفشل وإظهار تنبيه قابل للتصرف.
- [ ] الاختبارات تتم في sandbox قبل تفعيل الإنتاج.

## النسخ الاحتياطي والخروج
- [ ] نسخة احتياطية منفصلة ومشفرة.
- [ ] اختبار استعادة ناجح وموثق.
- [ ] تصدير يشمل البيانات والعلاقات والمرفقات اللازمة.
- [ ] اختبار استيراد عينة من التصدير.
- [ ] سياسة الاحتفاظ والحذف تغطي النسخ والسجلات والمرفقات.

## التشغيل
- [ ] اختبارات الوحدة والتكامل والرحلات الأساسية ناجحة.
- [ ] فحوصات الاعتماديات والثغرات شُغلت وتوثقت.
- [ ] مراقبة الأخطاء والتنبيهات تعمل.
- [ ] خطة rollback موجودة للترحيلات والإصدارات المهمة.
- [ ] تعليمات التشغيل والنشر والاستجابة للحوادث مكتوبة.

## الامتثال والاعتماد
- [ ] مراجعة قانونية موثقة للمتطلبات المنطبقة في مصر.
- [ ] اتفاقيات معالجة البيانات مع الأطراف ذات الصلة.
- [ ] توثيق مكان معالجة البيانات والنسخ والسجلات.
- [ ] ترخيص مكتوب لمصدر بيانات الأدوية إذا استُخدم تجاريًا.
- [ ] موافقة صريحة قبل استخدام بيانات حقيقية أو إرسال رسائل/تحصيل أموال فعليًا.

لا توضع علامة [x] إلا عند وجود دليل؛ اكتب رابط الاختبار أو التقرير أو رقم المهمة بجانب كل بند في سجل الحالة.
