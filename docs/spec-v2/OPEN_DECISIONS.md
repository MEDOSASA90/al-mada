# قرارات مفتوحة — ممنوع اختراع إجابة

هذه المسائل تحتاج تحققًا أو قرارًا من صاحب المشروع أو مختص. يمكن للوكيل إعداد مقارنة موثقة، لكنه لا يحسمها بالتخمين.

| القرار | المطلوب لحسمه | الوضع |
|---|---|---|
| الاستضافة داخل مصر | عروض أسعار، موقع كل نسخة ونسخة احتياطية، عقد، نطاق الخدمة، تحقق قانوني | مفتوح |
| امتثال حماية البيانات | مراجعة قانونية مصرية محدثة، الأدوار والالتزامات والتراخيص المطلوبة | مفتوح |
| مصدر قاعدة الأدوية | موافقة/ترخيص مكتوب للاستخدام التجاري والتحديث والتخزين والعرض | مفتوح |
| مزود الذكاء الاصطناعي | شروط الاحتفاظ والتدريب، مكان المعالجة، العقد، التكلفة، جودة العربية | مفتوح |
| مزود واتساب | المزود الرسمي/الوسيط، الأسعار الحالية، قوالب الرسائل، الموافقات | مفتوح |
| بوابة الدفع | التوافر التجاري، الرسوم، الاسترداد، التسوية، المتطلبات التعاقدية | مفتوح |
| التسعير النهائي | تكلفة فعلية لكل عيادة، حدود الاستخدام، دعم العملاء، الضرائب ورسوم الدفع | مبدئي فقط |
| مدة إتاحة التصدير | عقد وسياسة معتمدان ومراجعة الالتزامات القانونية | مقترح يحتاج اعتماد |
| RPO/RTO | أقصى فقد بيانات مقبول وزمن الاستعادة المطلوب والتكلفة | مفتوح |
| الاحتفاظ بالسجلات | نوع السجل والجهة المسؤولة والأساس القانوني والمدة المنطبقة | مفتوح |
| الميزات السريرية | مراجعة أطباء، تقييم مخاطر، اختبارات مرجعية وموافقة إطلاق | غير معتمدة |
| التقنية النهائية | مراجعة المستودع الحالي ومتطلبات الاستضافة والمهارات والتكلفة | تُحسم بعد اكتشاف الواقع |

## ملاحظات
- أسعار الباقات المذكورة في المخطط أسعار اختبارية وليست إثباتًا للربحية.
- استضافة البيانات داخل مصر لا تثبت وحدها الامتثال القانوني.
- توفر صفحة بحث عامة للأدوية لا يعني وجود حق استخدام تجاري أو واجهة API مرخصة.
- أي مدة احتفاظ أو تصدير في الملفات هي سياسة مقترحة وليست نصيحة قانونية نهائية.
